# v0.2.3：试玩反馈修复

发布日期：2026-11-10。

- 敌人改用朱红、赤褐暖色，玩家服装与队友饰边使用蓝青冷色。
- 每次波末选卡有三次刷新，支持按钮与 R；联机由房主维护每人的独立额度。
- 白天近处绿色山脊改为真实起伏地形，远山仍保留天空水墨背景；绿色山坡按可见模型生成实体碰撞。六个箱子使用各自贴合的碰撞，跳跃可越过箱顶。
- 普通敌人、墨将及其召唤援军从庭院外生成，沿入口走入；入口边界只限制玩家，移开阻挡路线的石灯并为入口留出碎石空隙。
- 血相关文案统一使用「血」。
- 墨爆增加蓝青法阵、符字与墨点；疾风步增加风痕；火符增加施放符字、焰尾和落点火纹。联机同步施放和火符命中特效，短租期节点按时释放。
- 步枪镜筒及装饰环改为空心结构，镜片透明，并校正瞄准轴线。
- 多人房间与游戏内队伍信息显示实测 RTT，覆盖直连和中转。

`feedback_audit.gd` 覆盖真实跳箱、昼夜两图各八个场外入口、山坡射线碰撞、暂停状态下刷新额度、镜筒通视和特效清理，共 84 项通过。双进程直连与中转用例新增真实 RTT、房主与客户端三次刷新和法术特效同步验证。渲染截图位于 `dev_shots/feedback_*.png`。


版本号、标题界面、本地打包名称和构建清单统一为 `0.2.3`；发布标签为 `v0.2.3`。本地 Windows 试玩包为 `dist/InkTide-0.2.3-Windows-x64.zip`，GitHub Actions 根据标签构建 Windows / Linux 客户端与中转服务。
