# v0.2.2：敌人空间声音与追击节奏

靠脚步和嘶吼判断敌人从哪里接近，同时应对新增的跳砍与旋风斩，让追击更紧张、命中后的反应更明确，是这一版的重点。此前的模型、命中判定、受击方向、设置与联机功能继续保留。

## 听清侧后方的威胁

六套基础敌声音色各有三种呼声和三种移动声：墨鬼是低喉气声与拖步，纸傀是纸刮与咔响，墨甲是甲片震动与重踏，墨将是低音战吼与铁靴。悬浮咒面使用带气吟啸与布擦，灯鬼使用呼火与链铃，避免把空中移动误听成落地脚步。新增跃魇复用纸傀音色，旋刃复用墨甲音色；当前八种敌人使用六套声音配置，不将复用音色计作新增独立录音。

`EnemyAudio` 根据实际位移累计步距，移动变快时节奏跟着加快；静止不会持续踏步，网络位置修正也不会补出一串虚假的追赶脚步。脚步在约 23 米内播放，呼声在约 28 米内播放，不按摄像机朝向剔除近处侧后方敌人。

持续呼声跟随仍存活的发声者，脚步留在实际发生的位置；敌人死亡、离树、超出范围，或者处于标题、暂停、出现阶段时，不会继续留下误导的位置声。墙体遮挡不会直接让声音消失，而是降低约 9 dB，并通过 1700 Hz 低通变闷。耳机或立体声音箱更便于判断左右和远近。

敌声拥有独立的 10 声部预算，脚步与环境嘶吼分别限量，并为攻击告警保留容量，不挤占枪声声部。联机代理的跳砍、落地与旋转阶段也播放对应挥刀 / 落击声，旋转挥刀声有间隔限制。近处蓄力 / 引燃时的告警优先；同一声源的攻击提示可以中断自己的环境嘶吼，并带 1.15 秒冷却，避免快速状态变化连续刷吼。所有敌声经世界音效总线进入 `Ink`，仍由「音效音量」控制。

## 更快追击，命中后短暂减速

敌人基础移动速度相较上一版统一提高 **18%**，原有波次速度缩放与 Boss 狂暴仍按既有规则计算。

**减速作用在被命中的敌人身上**：普通敌人减速 25%，墨甲 12%，墨将 8%，持续 0.28 秒。持续射击会刷新这段短暂迟滞，让命中有清楚的阻滞感；更强的冷墨减速与普通命中迟滞取较强值，不相乘，也不因每发子弹不断累叠减速。停止命中后，迟滞到期恢复追击速度。

## 新增特殊敌人

「跃魇」第三波起出现。它先蓄力 **0.75 秒**并锁定落点，再腾空约 **0.72 秒**；不会在空中继续追踪玩家修正落点。落地时只结算一次半径 **2.5 米**的范围攻击，基础伤害为 `17 × 1.35`，随后 **0.70 秒**硬直。看到落点圈后侧步离开，可以避开这一轮跳砍。特殊技能冷却 **4.8 秒**，从蓄力开始计算。

「旋刃」第六波起出现。它先预警 **0.90 秒**，再持续旋转 **1.70 秒**，横向移动为常态速度的 **40%**；半径 **2.9 米**内每目标至少间隔 **0.45 秒**结算一次，单次基础伤害 **12**。旋转结束后有 **0.80 秒**硬直，特殊技能冷却 **5.7 秒**，同样从蓄力开始计算。拉开距离或利用掩体规避斩击，等硬直时反击。

两者的基础数值分别为：跃魇血 110 / 移速 2.9 / 刷怪预算 5.2，旋刃血 190 / 移速 2.3 / 刷怪预算 6.8。这里是定义基准值，实战仍叠加公共速度、波次、难度与多人规则。两类敌人从对应波次加入常规刷怪池，第三 / 六波横幅提示躲避落点和旋风圈；近距离也有普通刀击。

蓄力阶段受到会心 / 暴击，或单次伤害达到最大血的 **14%**，可被打断并进入短暂恢复，但不会重置已开始的技能冷却。范围攻击检查墙体遮挡和垂直距离；跳跃撞墙会停止水平推进并下落。普通命中减速与冷墨仍可作用于它们，已腾空的惯性轨迹不会被事后减速改写。

## 声音素材与扩展

本轮增量生成 36 条原创敌声，全部为单声道 44.1 kHz PCM16：呼声约 0.79–1.46 秒，移动声约 0.23–0.49 秒。原来的枪声、配乐等 110 个 WAV 经 SHA256 检查保持字节不变；完整音库现有 146 个 PCM 文件、65 个兼容事件。

- 呼声 ID：`enemy_wraith`、`enemy_puppet`、`enemy_brute`、`enemy_mask`、`enemy_lantern`、`enemy_boss`。
- 移动声 ID：对应的 `enemy_step_<类型>`，每个 ID 三个变体。
- 增量生成：`python tools/generate_audio.py --enemy-only`。
- 波形与格式检查：`python tools/generate_audio.py --audit-only`；详情见 [音频说明](../assets/audio/README.md)。

新增或调整敌人不必改声音控制器。`EnemyDB.register_type()` 的定义字典可提供 `audio` 覆盖，继承类型的默认行为后再调整：

| 字段 | 含义 |
| --- | --- |
| `step_id` / `roar_id` | 音库中的移动声 / 呼声 ID |
| `stride` | 每次移动提示之间的实际水平距离，单位米 |
| `step_db` / `roar_db` | 对应声源的基础音量，单位 dB |
| `roar_gap` | 环境呼声的基础间隔，单位秒，播放时带小幅随机变化 |
| `floating` | 使用悬浮移动条件，避免要求地面接触 |

```gdscript
var definition := EnemyDB.get_type("wraith")
definition["audio"] = {
    "step_id": "enemy_step_wraith", "roar_id": "enemy_wraith",
    "stride": 0.9, "step_db": -5.0, "roar_db": -3.0,
    "roar_gap": 5.4, "floating": false,
}
EnemyDB.register_type("wraith", definition)
```

这里展示的是定义字典接口；当前 `EnemyDefinition` 资源尚未新增独立的音频导出属性。
