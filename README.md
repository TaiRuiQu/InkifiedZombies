# 墨潮 · Ink Tide — v0.2.3 内测

> 以墨为刃，独守长夜；与友同行，共候破晓。

水墨手绘风第一人称波次生存射击游戏。选择墨境与难度，用枪械、疾风步和局内升级守过十波墨潮；也可以和好友组成至多四人的小队。第 5、10 波迎战墨将，肃清第 10 波进入「破晓」结算，再选择继续无尽守夜。

v0.2.2 加入敌人的空间脚步、悬浮移动声与嘶吼，让身后和掩体后的威胁更容易定位；新增跳砍的「跃魇」与旋风斩的「旋刃」，敌人追击也更快，命中敌人会带来短暂减速，提供调整站位的窗口。详见 [v0.2.2 更新记录](docs/UPDATE-0.2.2.md)。下拉弹窗、地图预览、面部、命中与受击方向的前次修复保留于 [v0.2.1 打磨记录](docs/POLISH-0.2.1.md)。**平衡、目标硬件性能和真实公网体验仍需持续试玩验证。**

## 开始游戏

[v0.2.3 试玩反馈修复](docs/UPDATE-0.2.3.md)：敌人使用朱红／赤褐暖色，玩家与队友使用蓝青冷色；每次波末选卡可点击按钮或按 **R 刷新三次**，联机每人独立计数。敌人从庭院外侧进入，绿色山坡补齐模型与碰撞，箱子可跳上站立；血相关文案统一使用「血」。墨爆、火符与疾风步新增法阵、焰尾与拖影；步枪瞄准镜改为空心镜筒与透明镜片。多人房间和游戏内队伍信息显示实测连接延迟，直连与中转均支持。

Windows x64 试玩包位于 `dist/InkTide-0.2.3-Windows-x64.zip`。完整解压后，双击 `InkTide.exe` 或 `Start-InkTide.cmd`，无需安装 Godot；`InkTide.exe` 与 `InkTide.pck` 必须保留在同一文件夹。未压缩的客户端位于 `dist/client-windows/`。`dist/server/` 单独提供中转服务器。

`dist/` 是本地构建产物，不纳入 Git。克隆源码后可直接用 Godot 运行工程；客户端使用 `tools/build-client.ps1` 构建，中转服务使用 `server/build.ps1` 构建，详见各自说明。

GitHub Actions 会检查每次分支推送和 Pull Request；发布版本标签时自动构建 Windows / Linux 客户端与中转服务器，并上传 GitHub Release 附件。CI 客户端使用官方精简发布模板，详见 [自动构建与发布](docs/CI.md)。

客户端随附本机 Godot 4.7.2 编辑器构建作为运行时并加载独立 PCK，正常启动进入游戏；它尚未采用正式精简 release export template，包体较大。v0.2.3 成品已从不含工程的临时目录分别通过正常 Vulkan 渲染与无界面启动，退出码为 0，日志无错误或警告；完整试玩验证范围见对应更新记录。

开发者也可直接运行工程：

1. 使用本工程验证的 **Godot 4.7.2** 打开 `project.godot`，等待首次资源导入。
2. 按 **F5**。标题选择「残照庭院」或「青岚夜院」、难度与征途；右侧实时场景预览随地图切换，显示对应地标、灯光与雾色。
3. 点击「独守 · 单人」开始；「同守 · 多人」进入好友房间；「调墨 · 设置」调整偏好。

本机命令行示例：

```powershell
& "G:\Godot\Godot_v4.7.2-stable_win64.exe" --path "G:\InkifiedZombies"
```

默认使用 Forward+ 渲染。首次启动会编译着色器；尚未给出经过覆盖测试的最低硬件配置。

Web 版使用单线程 Compatibility / WebGL 2，已接入本地 Paper Agent 的 `/games/ink-tide/`。构建导入命令、浏览器画质、WS/WSS 中转与验证范围见 [Web 接入记录](docs/WEB-INTEGRATION.md)。在 Paper 页面中单人试玩不需要登录；创建联机房间需要已登录的 Paper 账号，Center 签发短时票据、中转校验签名后才建立房间。桌面版保留独立的直连与中转玩法，可继续不登录使用。游戏与中转仍可独立运行；浏览器版面向桌面键鼠。

## 玩法与操作

开局拥有「墨毫」手枪与 **E 疾风步**。保持移动、留意敌人蓄力，利用石碑和古井周旋。每波清场会回血、补充备弹、装满已持有武器并重置术法冷却；随后从三张升级卡中择一，或弃牌回复 30% 最大血。尚未获得第二把武器时，升级选择会优先保留一个武器解锁选项。

| 默认输入 | 动作 |
| --- | --- |
| WASD / Shift / Ctrl | 移动 / 冲刺 / 蹲伏 |
| 空格 | 跳跃 |
| 鼠标移动 / 左键 / 右键 | 瞄准 / 射击 / 机瞄 |
| R / V | 装填 / 近战笔击 |
| E | 疾风步，开局可用 |
| Q / G | 墨爆 / 火符，升级后解锁 |
| 1–6 / Tab / 滚轮 | 按持有顺序切换武器 |
| Esc | 暂停菜单 / 返回 |
| 升级时 1 / 2 / 3 | 选择升级卡 |

「调墨」可重绑 21 个核心操作。Esc、系统功能键与滚轮保留；重绑会检查冲突，Esc 取消等待输入。菜单支持 Tab 聚焦与 Enter / 空格激活。标题与设置的下拉弹窗使用纸纹、墨字和朱砂选中印章。

| 难度 | 体验 |
| --- | --- |
| 初入墨境 | 较少敌人、更低承伤、更充分的波间回复 |
| 守夜人 | 标准预算、伤害与补给 |
| 墨潮试炼 | 更高敌量与强度、较少波间回复 |

默认征途为十波试炼；也可开局选择无尽，或在通关后继续。敌人、枪械和技能升级均在本局内成长；当前没有局外货币或永久属性养成。

v0.2.2 将敌人的基础移动速度统一提高 18%。命中敌人会使其短暂减速：普通敌人 25%、墨甲 12%、墨将 8%，持续 0.28 秒；重复命中刷新这段时间，配合更强的冷墨效果时采用较强减速，不把倍率相乘或连续叠加至停滞。

## 内容与模型

两张地图共用水墨建筑语言，拥有不同的地标与碰撞布局、日月光照、雾色和植被配置：残照庭院适合熟悉操作，青岚夜院改变碑、井、石柱位置，提供月下竹影氛围。标题下拉选择会重建实际预览场景，开局沿用当前预览的地图。

| 武器 | 特点 |
| --- | --- |
| 墨毫 | 初始手枪，精准可靠 |
| 泼墨铳 | 近距离多弹丸爆发 |
| 狼毫 | 大弹匣、高射速冲锋枪 |
| 朱砂 | 重型步枪、穿透射击 |
| 泼墨炮 | 抛物线墨弹、范围爆炸 |
| 雷纹弩 | 单发重击、长距离穿透 |

全部六把第一人称武器加入机械开口、护圈、瞄具、铆钉与符纹细节，配合可动套筒、泵动部件、双手手套及装填动作。模型与武器控制已拆分，支持自定义场景替换。

| 敌人 | 轮廓与细节 |
| --- | --- |
| 墨鬼 | 破面、缝线丧服、骨指与咒印，基础追击者 |
| 纸傀 | 折纸边、铜关节、纸手，快速而脆弱 |
| 墨甲 | 层叠甲片、铜钉、护腕护胫、狼牙棍，慢速重击 |
| 咒面 | 骨鼻裂纹、法轮、念珠、飘符，远程拉扯 |
| 灯鬼 | 竹骨架、烧纸裂缝、提环、流苏与火芯，近身自爆 |
| 跃魇 | 第三波起出现；蓄力锁定落点后跳砍，可侧步躲开落地范围 |
| 旋刃 | 第六波起出现；预警后旋转逼近，拉开距离并抓住结束硬直 |
| 墨将 | 层甲金冠、绶带、护臂与异形戟刃，阶段攻击与召唤 |

跃魇蓄力 0.75 秒、腾空约 0.72 秒，落点锁定后不会在空中追着玩家修正；离开 2.5 米落地区域即可规避。旋刃预警 0.9 秒，随后旋转 1.7 秒，在 2.9 米内连续斩击，结束后有 0.8 秒硬直。两者蓄力时受到会心 / 暴击或单次至少 14% 最大血的伤害可被打断；第三 / 六波横幅会提示对应躲法。

八种敌人包含六类基础敌人与两种特殊敌人。面部使用手工分面的低多边形网格，形成眉骨、眼眶、鼻梁、颧骨、下颌和牙齿深度；不同敌人保留各自头型、表情与纸面折线。移动胶囊与头、躯干、肢体的受击区域分开，头部和活动手臂不再受窄移动胶囊限制。

场景新增曲檐瓦当、斗拱、墙脚、祭阵、古井绞盘、道具格栅与自然碎叶；细节使用批次合并或 MultiMesh，减少单个装饰物的绘制开销。多人队友具备分色服装、斗笠、持枪与步行动画。血拾取物补充瓶颈与瓶塞，弹药卷轴补充端帽，墨弹加入符文细节；描边和纸感材质继续采用程序化实现，没有引入外部写实模型包。

## 命中与受击反馈

枪口至弹着点的实际碰撞路径用于绘制曳光，靠墙时先修正枪口位置，避免视觉弹道穿过掩体。可见头部、躯干和肢体拥有独立受击区域；穿透命中同一敌人后会排除其全部区域，防止一发子弹重复扣血。敌人出现动画期间也可受击。

射击加入更明确的后坐、枪械机械动作与抛壳；命中、会心、爆头和斩杀拥有不同准星反馈、文字确认及音效，敌人有受击反应。受击后 HUD 用方向标记与文字提示攻击来源，转动视角时仍跟踪世界方向；护盾和血受击分色。关闭镜头晃动或受击闪烁后，方向提示仍可使用。联机客户端的命中与斩杀确认由房主实际伤害结果触发。

## 音效与配乐

音频由离线生成的原创 PCM 文件提供，无需在开局时合成长段声音。65 个事件包含六枪各三个变体、肉体 / 护甲命中、爆头 / 击杀确认、护盾 / 血受击、装填三阶段、石地 / 纸面脚步、弹壳，以及六套基础敌声音色各三种呼声和三种移动声；跃魇复用纸傀音色，旋刃复用墨甲音色，八种敌人不是八套独立录音。连续播放避免重复同一变体。

敌人脚步按实际移动距离生成，停住时不会继续踏步；咒面和灯鬼分别使用布擦、链铃等悬浮移动声。附近侧后方的敌人仍能听见，持续嘶吼跟随声源，隔墙会衰减并变闷。敌声使用独立且有限的声部，避免尸潮提示挤掉枪声；它们仍由音效音量控制。

原创配乐以 80 BPM、16 小节的 48 秒乐段分层编排，包含拨弦旋律、持续弦乐、战鼓、Boss 加强层和独立环境声。菜单、战斗、波次强度、修习与 Boss 状态通过交叉淡化改变编曲，保持同一播放时间轴。枪声会短暂压低配乐，混音总线具备峰值限制。背景音乐可与音效、环境音分别调节。[音频生成与试听说明](assets/audio/README.md)

## 设置与存档

标题与暂停菜单均可打开设置，调整即时生效并自动保存：

- 画面：窗口 / 无边框 / 独占全屏、窗口分辨率、垂直同步、帧率上限、三档画质、视野。
- 声音：主音量、音效、环境音、背景音乐分别调节，支持静音与试听。
- 操作：鼠标灵敏度、反转纵轴、键鼠重绑定。
- 舒适：镜头晃动、受击闪烁、伤害数字、准星大小。

偏好保存在 `user://settings.cfg`；本地战绩保存在 `user://ink_tide.cfg`，包含到达 / 肃清波次、局数、通关数和最近十局记录。两者分开写入，使用临时文件再覆盖。`user://` 为 Godot 用户数据目录，具体位置可由 `OS.get_user_data_dir()` 查询。

## 好友联机

进入「同守 · 多人」，填写昵称后选择连接方式。房主决定地图、难度与征途；好友就绪后由房主开始。允许房主独自试开，房间最多四人。

| 方式 | 服务与端口 | 使用方法 |
| --- | --- | --- |
| 直连 | 房主客户端，ENet / UDP 7777，可修改 | 同一局域网填写房主局域网 IP；跨网需房主端口可达及必要的路由 / 防火墙配置 |
| 中转 | 独立中转服务，WebSocket / TCP 7778 | 所有人连接同一个中转地址，通过房间码与可选密码进入；玩家通常无需本地端口映射 |

中转服务器可直接运行：

```powershell
.\dist\server\ink-tide-relay-windows-amd64.exe -addr :7778
```

```sh
chmod +x dist/server/ink-tide-relay-linux-amd64
./dist/server/ink-tide-relay-linux-amd64 -addr :7778
```

游戏默认测试地址为 `127.0.0.1`，对应 `ws://127.0.0.1:7778/ws`；也接受服务器 IP、`主机:端口` 或完整 WS / WSS 地址。跨电脑时改成中转机器的局域网或公网地址；`127.0.0.1` 仅指向玩家自己的电脑。部署机器须开放 TCP 7778；公网长期部署可使用 WSS。详细部署、TLS、服务参数与协议见 [server/README.md](server/README.md)。

对局由房主执行敌人、伤害、掉落和升级判定，中转仅转发数据。队友倒下后可等待存活队友肃清本波，再复活归队；全队倒下则失败。每人独立选升级，全员完成后进入下一波。多人打开暂停 / 设置时战斗继续。房主断线会中止会话，当前没有房主迁移、自动重连或账号匹配；返回标题后重新建房 / 加入。
